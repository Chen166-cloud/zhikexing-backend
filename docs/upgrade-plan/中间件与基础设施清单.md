# 中间件与基础设施清单

核对日期：2026-09-26。本清单以知课行三个仓库源码和 `docker-compose.yml` 为准。消息通道使用 RocketMQ；MySQL Flyway V1–V7 新库迁移、Java 单测、前端构建、隔离真实 Redis/RocketMQ 的 15+3 项集成测试以及 `zhikexing` 完整 Compose 的 Agent fixture 跨服务烟测通过。真实浏览器完成注册、登录、产品首页、工作台和试听页面导航，控制台没有错误。组件数是**类型数**，不是容器数或生产高可用等级；真实外部模型、真实 API 的 MEMBER 浏览器权限与浏览器 Agent 审批未验收。

## 1. 当前组件统计

| 类别 | 类型数 | 组件 | 在项目中的职责 |
|---|---:|---|---|
| 核心数据与异步处理 | 5 | MySQL、PostgreSQL + pgvector、Redis、RocketMQ、MinIO（S3） | 业务最终账、Agent 持久化与检索、登录及试听原子预占、异步命令与落单、原文对象 |
| 观测与监控 | 4 | Langfuse、ClickHouse、Prometheus、Grafana | 模型轨迹、分析存储、运行指标、看板 |
| 入口与遥测 | 2 | Nginx、OpenTelemetry Collector | Vue/API/SSE 反向代理、遥测转发 |

合计 **11 类**。Langfuse 自托管的 PostgreSQL、Redis 和对象存储可使用独立实例/桶，但不增加组件类型数；pgvector 是 PostgreSQL 扩展，不另算数据库。Java、Python、Vue 应用及百炼托管模型 API 不计入中间件。Compose 中的 Broker 单节点和单 Python worker 是开发演示形态，不代表多副本容灾。

## 2. 数据与消息职责

| 组件 | 当前承担的功能 | 一致性或运维边界 |
|---|---|---|
| **MySQL** | 用户、空间、成员、课程、校区、审批、普通预约、任务接收与 outbox；试听活动、参与请求、最终库存和 0 元订单 | Java 持有业务真相。新写入主键由应用雪花算法生成；V6 保留已有单列数值主键并为原复合键、聊天记录补代理主键。应用表无自增列与物理外键，服务层校验逻辑关联，数据库唯一键和事务约束仍保护业务不变量。试听订单以事务提交判定，不以缓存或模型回答判定 |
| **PostgreSQL + pgvector** | Python 运行、消息、事件、LangGraph checkpoint、知识版本/片段/向量和评测 | 不直接修改试听库存或订单；checkpoint 不能替代 Java 业务幂等 |
| **Redis** | 登录态、短期缓存、试听活动窗口及 Lua 原子预占、同人参与去重、限流 | 试听预占使用 AOF + noeviction；丢失时暂停受理并依据 MySQL 对账，不能直接按剩余库存自动回填 |
| **RocketMQ** | `zhikexing-agent-commands` 普通命令；`zhikexing_trial_claims` 试听事务消息；重试和死信 | Java 普通命令消费者经内部 HTTP 交给 Python，Run/取消状态持久化后才确认。试听半消息回调执行 Redis Lua；已提交消息由 Java 异步落单。均允许重复投递，接收端幂等 |
| **MinIO（S3）** | 文档原文、观测对象，不存储试听业务最终账 | 授权下载、对象引用与桶隔离；云 OSS 是可替换部署选项，当前 Compose 采用 MinIO |

试听链路的阶段为：MySQL 先持久化请求 → RocketMQ 半消息 → 本地事务回调用 Redis Lua 预占并保存结果 → 提交消息 → 消费者 MySQL 条件扣库存和创建 0 元订单 → 用户在 `/agent`“免费试听”标签查看本人记录或按原 `requestId` 查询。`PENDING` 和 `RESERVED` 不是成功，只有 `SUCCEEDED + orderId` 才是成功。具体故障恢复与验证见[模块设计](../modules/免费试听秒杀与Agent联动.md)和[验证记录](../modules/免费试听秒杀验证记录.md)。

## 3. 观测、入口与遥测

| 组件 | 作用 | 不承担的职责 |
|---|---|---|
| Langfuse | 模型调用、用量及 Agent 轨迹分析 | 不保存试听订单最终账或完整产品会话 |
| ClickHouse | 自托管 Langfuse 分析存储 | 不替代 MySQL/PostgreSQL 业务库 |
| Prometheus | Java/Python/Broker 指标，包括试听事务、发送与消费重试 | 计数器包含重试，不直接等于唯一订单数 |
| Grafana | 指标看板与趋势 | 不直接采集或持久化业务交易 |
| Nginx | 托管 Vue，转发 API 与 SSE | Python 内部工具仍由 Java 校验身份 |
| OpenTelemetry Collector | 接收与转发 OTLP 遥测 | 不承担长期数据存储 |

## 4. 尚未纳入当前部署的可选组件

Elasticsearch 只在词法检索基线证明明显不足后评估；LiteLLM Proxy 只在多提供方路由确有需求后评估；vLLM 需有自部署模型和硬件实验；Temporal 需有跨服务长流程需求并先划清与 LangGraph/现有恢复器的边界。它们不计入当前 11 类。百炼 `qwen3.7-flash` 与 `text-embedding-v4` 是托管模型服务；Spring Boot、FastAPI、LangGraph、Flyway、SSE、MCP、Docker 等是框架、工具或协议，也不混入中间件数量。

组件实际端口、容器拓扑、启动、备份和迁移操作见[Docker 部署文档](../deployment/Docker部署文档.md)。
