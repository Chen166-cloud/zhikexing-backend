# 技术资料与开源项目阅读清单

调研/访问日期：2026-09-17；模型选型补充：2026-09-18。配套主方案：[2027 AI Agent 改造研发方案](2027-AI-Agent-改造研发方案.md)。

本清单收录本次检索并查阅的官方项目、规范、技术博客和开源代码，共 42 个编号资料入口。只用一手材料支持技术判断；搜索结果中的社区讨论、转载和聚合站仅用来发现线索。开源功能和公司公开实践不等于所有公司统一采用某套技术栈。

动态文档与 main 分支会更新。正式开发时应记录 tag/commit、依赖 lock 与评测配置；这里的链接是调研入口，不是已经替你做好的兼容性认证。

模型接入按已确定的目标方案阅读和实验：日常 Agent 使用阿里云百炼 `qwen3.7-flash`，Embedding 保持 `text-embedding-v4` 与现有 1024 维，共用一把百炼模型 API Key。配置约定与实施边界见[模型服务与 API 配置](./模型服务与API配置.md)；本次只同步文档，不表示程序已经完成切换。
