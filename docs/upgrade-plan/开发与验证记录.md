## 当前实现边界

真实知识评测已经执行 3 条合成样本（本机评测 ID `dea0dc4c-5ba2-4036-a534-d78b6a97c05c`）：2 条有参考断言均通过，1 条无断言保持未评分；三条平均延迟 1007 ms，聊天模型共 947 Token，按价格快照估算 0.0002404 元。它是接口与引用的冒烟证据，不是通用准确率、并发性能或 300 条正式测试集结果；费用不含 Embedding。

- 单 worker 通过持久化 checkpoint 恢复，并允许多个不同会话并行；尚不声明完成多 worker 租约/fencing。
- 默认解析器支持有文本的 PDF；Docling/OCR、本地 BGE 为可选扩展，开启前必须独立验证依赖、模型与资源。
- 混合检索当前为 pgvector + 中文词项排序/RRF，尚未把它标为 Elasticsearch/BM25。
- 评测判定采用规则、文档命中和人工可复核结果；模拟模型测试不算业务效果数据，未编造 300 条真实评测成绩。
- 用户要求测试完成后删除本次新增测试类和脚本；保留生产评测功能、去敏验证报告和操作说明。已有用户测试文件不擅自删除。
- 三个仓库各有构建 CI。当前已验证本地对应构建、依赖与 YAML；尚未向远程推送、触发 GitHub Actions，不能记作远端 CI 已通过。
