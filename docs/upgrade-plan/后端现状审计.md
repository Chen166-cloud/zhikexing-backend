## 对研发方案的建议

建议把当前四个入口收敛成“有证据引用、可审批执行、可恢复和可评测的业务 Agent 平台”。Java 可保留为业务与权限主干；是否引入 Python graph/runtime、MCP 或向量数据库应由目标岗位和具体功能决定，避免把依赖清单扩张等同工程进步。先解决上面真实失败模式，然后用其对应的测试和演示建立亮点：双用户隔离测试、检索版本替换不串文档、失败重试与原文可用、人工审批不可越过、工具重复请求只生成一单、同一会话并发一致性、断线回放、进程重启恢复、RAG 标注集前后对照、延迟/成本/成功率分项看板。每个指标在真正测量前写目标/验收门槛，不写成履历成果。
