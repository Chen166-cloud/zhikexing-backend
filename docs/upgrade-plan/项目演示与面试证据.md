# 项目演示与面试证据

更新日期：2026-09-25。以下演示使用合成课程与用户，范围以[试听模块验证记录](../modules/免费试听秒杀验证记录.md)为准。新版本的真实中间件隔离集成和 fixture 模型跨服务演练已完成；常用完整 Compose 与试听链路真实模型演示尚未验收。不要将设计目标或模拟负载写成生产数据。

## 演示顺序

1. 展示三仓库架构：Vue 工作台，Java 持有身份、审批和业务账，Python LangGraph 持有运行状态；MySQL、PostgreSQL/pgvector、Redis 和 RocketMQ 各有明确职责。
2. 以合成 PDF/课程演示知识查询、证据引用和普通预约草稿，说明 Java 固定审批参数，模型不能直接写业务表。
3. OWNER 通过 API 创建并发布 8 名额试听活动；页面目前只有 Agent 审批卡，活动运营与直接抢课入口仍为 API。
4. 让 Agent 查询活动并生成 `claim_trial` 草稿。批准后展示同一 `actionId` 的参与请求，明确 HTTP 202、审批 `EXECUTED`、`PENDING/RESERVED` 都不是订单成功。
5. 用原 `requestId` 回查最终状态：只有 `SUCCEEDED + orderId` 证明已获免费试听资格；展示 0 元订单、库存与 OWNER 对账结果。
6. 展示隔离测试中 40 名合成参与者争抢 8 名额、成功消息重复消费 3 次后只有 8 笔订单的记录；解释事务回查、MySQL 条件库存、唯一键和失败补偿分别解决什么。
7. 展示下一步验证：完整 Compose 重建、真实模型选工具、浏览器交互、Broker/Redis 故障恢复及容量测试。

## 简历措辞

**AI Agent 研发：** 设计独立 FastAPI/LangGraph Runtime，支持检索证据、人工审批暂停与恢复；将免费试听抢课建模为查询活动、固定参数草稿、批准后以稳定 `actionId` 提交、跨运行回查订单终态的工具链。Java 持有身份和业务真相，Agent 不凭自然语言宣布订单成功。

**Java 后端开发：** 在 Java 21/Spring Boot 4.1.1 服务中实现 MySQL 持久请求、Redis Lua 原子预占、RocketMQ 事务消息和异步 0 元订单；通过库存条件更新、唯一约束、事务回查、恢复器与对账处理重复投递及不确定状态。同一 Broker 承载 Agent 普通命令，Java 消费者通过内部 HTTP 将命令交给 Python 幂等接收。

可引用的正确性数据：隔离真实 MySQL/Redis/RocketMQ 环境中 40 名合成参与者竞争 8 个名额，成功消息重复消费 3 次后最终 8 笔订单；Java 19 项、Python 14 项专项回归通过。它们不是 QPS、p95、真实用户规模或线上效果。新增试听端到端使用 fixture 模型，不写成真实模型验证。

## 面试追问与证据

| 问题 | 关键回答 | 证据 |
|---|---|---|
| 为什么 Agent 不直接执行抢课？ | 模型只能查询和起草；用户批准固定活动参数，Java 再按可信 actor/workspace/run 执行 | [产品契约](../product/产品功能说明书-研发版.md)、[模块设计](../modules/免费试听秒杀与Agent联动.md) |
| 事务消息为何还需要幂等？ | 半消息与本地事务缩小不确定窗口，消费者仍可能重复；请求、库存条件更新和订单唯一键决定最终结果 | [模块设计](../modules/免费试听秒杀与Agent联动.md)、[验证记录](../modules/免费试听秒杀验证记录.md) |
| 为什么预占成功不等于抢到？ | Redis 只是准入层；消费者 MySQL 事务提交并返回 `SUCCEEDED + orderId` 才是订单事实 | [接口契约](研发接口契约.md)、[模块状态](../modules/免费试听秒杀与Agent联动.md) |
| Redis 丢失活动库存怎么办？ | 停止受理，保留持久请求与订单，对账和人工裁决；不能按数据库剩余量覆盖预占键 | [恢复边界](../modules/免费试听秒杀与Agent联动.md) |
| checkpoint 已保存为何仍需 actionId？ | Java 业务已提交而图尚未保存下一节点时会重放，原 actionId 查回同一业务结果 | [接口契约](研发接口契约.md) |
| 40 人/8 名额证明了什么？ | 证明该隔离条件下无超卖和重复订单；没有证明更高并发、生产可用性或性能指标 | [验证记录](../modules/免费试听秒杀验证记录.md) |
